# 04. Идеи (бэклог без обязательств)

Ничего отсюда не входит в первую реализацию, если не помечено «MVP-кандидат».

## Edit и Look
- **Сравнение** *(MVP-кандидат)*: удержание `\` = Before; потом — сплит-экран с перетаскиваемой линией.
- **Look — избранные и недавние** *(MVP-кандидат)*: фильтры Favorites / Recent уже в макете, данные есть в `GradeLibrary` (favorite, lastUsed).
- **Копировать / вставить Look** на другое фото; **Apply to all** на ленту (пакетная обработка).
- **Рецепты обработки**: сохранить «Preset + LUT + рамка + Amount» как один Look-шаблон и применять одним кликом.
- **Сравнить два Look**: две плитки рядом на холсте.
- **Гистограмма** сверху инспектора (как у Lightroom/Capture One), сворачиваемая.
- **Adjust-блок** (если решение 2.5 изменится): экспозиция, контраст, температура, насыщенность, света, тени. Место зарезервировано во вкладке Look.
- **Кэш миниатюр Look** на диске (ключ: хэш фото + id Look + Amount 100): плитки открываются мгновенно.
- **Ленивые миниатюры**: считаем только видимые плитки, остальные скелетоны.
- **Подсказка о подмене**: у пресета с «Not applied …» — ссылка «Why?» с объяснением, что приложение не умеет (Clarity, Dehaze…).
- **Встроенные Looks** с проверенной лицензией и файл `docs/licenses.md` (сейчас не добавляем).

## Фото и поток работы
- **Drag & drop** фото и папок в окно; drop `.cube` / `.xmp` / `.zip` = импорт.
- **Sidecar** `фото.phspectre.json` рядом с оригиналом: состояние правок переживает перезапуск (неразрушающе).
- **Единый `EditState` на фото**: результат Look автоматически идёт во Frame (и, как идея, в Collage).
- **Недавние папки** и «последняя открытая» при запуске (приложение открывается сразу на фото).
- **Оценки/флажки** на ленте (pick / reject) — только если понадобится.
- **Сравнение с оригиналом камеры**: показать JPEG камеры (с Fuji-рецептом) рядом с Look.

## Frame, Collage, Camera
- **Frame**: «Карточки-пресеты» (минимализм, плёнка, polaroid-подпись); предпросмотр на экране, как для Looks.
- **Collage**: шаблоны сеток с миниатюрами, а не слайдер Gutter + Aspect.
- **Camera**: «Send this Look’s recipe» — из Edit предложить ближайший рецепт Fujifilm (отдельная большая тема, не сейчас).

## Приложение и интерфейс
- **Command palette** (`Ctrl+K`): быстрый поиск Look, режимов, команд.
- **Тосты вместо отдельных окон** для ошибок пакетной обработки.
- **Диалог «About»** вместо блока внизу Export (+ версия, обновление, лицензии).
- **Панели скрываются** (`Tab`): холст на весь экран; `F` — режим просмотра.
- **Настраиваемая ширина** инспектора (ручка у границы, 320–440).
- **Окна на мониторе 4K / ultra-wide**: левая колонка с библиотекой Look рядом с холстом (трёхпанельный режим) при ширине ≥ 1600.
- **Доступность**: полная навигация клавиатурой по плиткам (стрелки), `AutomationProperties.Name` у каждой плитки, масштабирование шрифта (125–150%) без поломки сетки.
- **Локализация**: строки в ресурсах (русский / английский) — сейчас всё на английском.
