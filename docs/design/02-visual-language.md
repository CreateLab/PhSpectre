# 02. Визуальный язык

Это спецификация, `Styles/*.axaml` пока не трогаем. Значения те же, что в `mockups/tokens.css`, поэтому эскизы показывают именно то, что потом будет в приложении.

## Направление

**Тихий, нейтральный, плотный инструмент.** Стиль «Minimalism / Swiss» из ui-ux-pro-max (`style` домен): много воздуха вокруг холста, плотные панели, один акцент. От предложенной скиллом палитры «Photo Editor & Filters» (фиолетовый `#7C3AED` + циан `#0891B2`) отказываемся: яркий цвет интерфейса спорит с цветом фото. «OLED чёрный» тоже не берём: холст `#1A1A1C`, не `#000`.

## Слои токенов (скилл design-system)

```
Primitive → Semantic → Component
--gray-900 → --surface-panel → --inspector-bg
```

Primitive нужны только в спецификации; в Avalonia остаются Semantic (как `Colors.axaml`) и несколько Component-токенов.

### Контраст (WCAG 2.2, рассчитан скриптом)

Текстовые пары (порог 4,5:1; все проходят):

| Пара | Dark | Light |
|---|---|---|
| `text` на `panel` / `surface` / `bg` | 16,5 / 15,2 / 17,2 | 18,4 / 16,2 / 17,0 |
| `text-2` на `panel` / `surface` / `bg` | 7,1 / 6,5 / 7,4 | 7,4 / 6,5 / 6,9 |
| `text-muted` на `panel` / `surface` / `bg` | 5,4 / 5,0 / 5,6 | 5,3 / 4,6 / 4,9 |
| `accent` на `panel` | 10,2 | 6,7 |
| `success` / `warning` / `error` на `panel` | 9,8 / 12,1 / 8,1 | 5,5 / 6,1 / 6,1 |
| `on-accent` на `accent` | 10,7 | 6,7 |

Границы интерактивных контролов (порог 3:1): `border-strong` на `panel` = 3,65 (Dark), на `surface` Light = 3,63. Декоративные разделители (`border`) порога не проходят и не должны использоваться как единственный признак контрола.

## Типографика

Один шрифт UI + моно для чисел. Скилл (`typography`, «Minimal Swiss») предлагает Inter/Inter; Inter уже подключён в `PhSpectre.Desktop` (`WithInterFont`).

| Роль | Размер / вес | Применение |
|---|---|---|
| `caption` | 11 / 500 | подписи плиток, счётчики (минимум: меньше 11 нельзя) |
| `small` | 12 / 400 | подсказки, мета |
| `body` | 13 / 400 | основное |
| `label` | 13 / 600 | заголовки секций, кнопки |
| `title` | 15 / 600 | заголовки панелей |
| `display` | 20 / 600 | пустые состояния |
| `mono` | 12 / 500 | числа (Amount, размеры, ISO) — JetBrains Mono |

Решение по Space Grotesk: **пока оставить для заголовка приложения** и сравнить в макетах; если разницы нет — убрать (меньше шрифтов, меньше веса). Решаем после эскизов.

## Отступы, радиусы, плотность

- Шкала 4 pt: 4 · 8 · 12 · 16 · 24 · 32. Внутри панелей — 12/16, между секциями — 24.
- Радиусы: `sm` 6 (чипы, поля), `md` 10 (плитки, карточки), `lg` 16 (шторки).
- Плотность: «standard-dense» (десктоп-инструмент): строка контрола 32–36, плитка Look 96×72 + подпись.
- Цели касания: **48 dp** на Android, 44 pt на iOS (единый токен `TouchTarget = 48` на мобайле); на десктопе — мин. 28 с зазором 8 (WCAG 2.2: 24 CSS px).

## Движение

- Токены: `fast` 120 мс (hover/press), `base` 200 мс (панели, вкладки), `slow` 320 мс (шторка). Ease-out; выход быстрее входа.
- Анимируем только `opacity` и `transform` (без ширины/высоты).
- Respect `prefers-reduced-motion` (на Avalonia — системная настройка «Show animations»): без параллакса, только crossfade 0–100 мс.
- Смена вкладок инспектора: crossfade 120 мс; смена режима: без слайдов (фото остаётся на месте).

## Иконки

Material Icons (как сейчас), размер 16 (в тулбарах) и 20 (вкладки). Иконка-только кнопки обязательно с `AutomationProperties.Name` и tooltip.

## Компоненты (спеки)

### Top bar segment (режимы)
Высота 32, иконка 16 + текст 13/600. `default` text-2 · `hover` text · `selected` accent-soft фон, text · `focus` кольцо 2 px accent · `disabled` text-muted 50%.

### Tab strip (инспектор)
Три вкладки, иконка 20 + подпись 11. Выбранная: accent иконка + 2 px линия снизу. Высота 52. Подпись всегда видна (не только иконка).

### Look tile
96×72 миниатюра (отрендерена на фото) + имя 11/500 в 1 строку с многоточием; звезда в углу (выбранная — акцент), бейдж «LUT/PRESET» 9→11 px caption под миниатюрой. Состояния: default (border), hover (border-strong), selected (2 px accent + галочка), loading (скелетон), error (иконка ⚠ + «Can't load»).

### Amount slider
Трек 4 px, ползунок 16 px (область нажатия 32/48), значение mono справа, шаг 1, `Shift` — 10. Двойной клик — сброс на 100.

### Chips-фильтры
Высота 28, радиус 6, `selected` accent-soft + text; прокрутка по горизонтали, без переноса.

### Accordion-секция (More)
Заголовок 13/600 + шеврон; по умолчанию свёрнута; состояние запоминается на режим.

### Filmstrip tile
Десктоп 96×62, мобайл 72×52 (единые токены `film.w/h`), выбранная — кольцо accent, экспортированная — зелёная метка.

### Export bar
Одна строка: имя файла (editable), размер, кнопка Export (`primary`). Тот же `ExportCommand`.

### Toast
Внизу по центру холста; иконка статуса + текст + действие («Show»). Авто-скрытие 5 с, пауза при hover. Ошибка не скрывается сама.

### Bottom sheet (мобайл)
Радиус `lg`, граб 36×4, высота 55% (peek 12%), scrim; ТОЛЬКО одна вкладка инспектора. Закрытие — свайп вниз / «Done».

| Экран | Пусто | Загрузка | Ошибка |

## Проверка перед поставкой (чеклист скилла для нативного UI)
- Иконки только SVG/Material, без эмодзи; иконка-кнопки с подписью для скринридера.
- Hover/pressed/focus/disabled у каждого контрола; видимый фокус с клавиатуры.
- Тема Light и Dark проверены на всех экранах; контраст по таблице выше.
- Минимальная ширина 980 (десктоп) / 360 (телефон) без горизонтального скролла.
- Motion по токенам; reduced-motion отключает декоративное.
